# Minorly Lens logo

The mark combines a lens and a percent sign on a soft lavender tile, using the
calculator's lavender/charcoal direction. It is an original generated asset,
created on 24 October 2026 with the built-in image-generation tool and one cleanup
edit. No third-party logo was used as an input.

`logo-master.png` is the selected transparent master. `public/icons/icon-16.png`,
`icon-32.png`, `icon-48.png` and `icon-128.png` are downscaled PNG exports. The
master is source artwork and is not copied into the extension package. The
committed exports need no extra runtime or build dependency.

## Generation brief

Create one original logo for Minorly Lens, a precise money/fee calculator Chrome
extension. A centered geometric magnifying lens surrounds a percent sign: two
round dots and one diagonal stroke. Use a soft lavender rounded-square tile and
deep charcoal symbol, balanced spacing and a strong silhouette readable at 16px.
No text, wordmark, mockup, extra options or copying another brand. Leave equal
transparent padding around the tile, targeting 75% artwork width/height.

## Cleanup prompt

Preserve the lens/percent composition, proportions and lavender rounded-square
identity. Remove edge noise, white flecks and stray marks. Use flat lavender
`#bba5f8` and charcoal `#24212e`, smooth edges, no grain, shading or extra elements,
and genuinely transparent padding on a square canvas.

## Export check

Export the complete master at each target size while retaining alpha. Inspect at
native size against light and dark backgrounds; do not flatten the transparent
padding. Check icon dimensions and the actual Chrome toolbar after rebuilding.
