# Minorly Lens Privacy Policy

Effective date: 24 October 2026. Applies to Minorly Lens version 0.1.0.

## What the extension does

Minorly Lens estimates transaction fees, platform markup, buyer totals and seller
proceeds using the amounts and fee rules you enter.

## Information you enter

Amounts, currencies, fee rules and allocation percentages are processed locally
in the extension to calculate and display your estimate. These values remain in
memory while the popup is open. The extension does not persist your form values
or calculation history; closing the popup resets them.

## Collection and sharing

Minorly Lens does not send your inputs or results to the developer or any third
party. It has no accounts, analytics, advertising, tracking, payment processing or
remote API calls. Its code and fonts are included in the extension package.

The extension requests no browser permissions or website access. It does not read
the websites you visit, your browsing history, page content or cookies.

## External services

Installing or updating through the Chrome Web Store involves Google's services
and their own policies. Visiting the GitHub repository or contacting us through
GitHub also involves GitHub's services. These are separate from the extension's
local calculations.

## Changes

If a future version adds saved drafts, website detection or a remote service, we
will update this policy to describe the resulting data handling. Such features
are not present in version 0.1.0.

## Contact

Contact the maintainer through the
[Minorly Lens issue tracker](https://github.com/geraldAp/minorly-lens/issues).
Issues are public; do not include sensitive financial information or personal
details in your report.
